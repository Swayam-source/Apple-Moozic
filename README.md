# Apple Moozic

A Liquid-Glass Android music player with high-resolution audio streaming, offline playback, time-synced lyrics, and native Discord Rich Presence (`Listening to Apple Music`).

## Key Features
- **Liquid Glass UI** — Real-time backdrop blur, dynamic album-art mesh gradients, and spring motion.
- **Native Discord Rich Presence** — OAuth2 PKCE handshake + Discord Social SDK broadcasting `Listening to Apple Music` with cover art, artist, song title, and live timestamps.
- **Time-Synced Lyrics** — Word-by-word and line-synced lyrics with distance blur and tap-to-seek.
- **Lossless & Offline Playback** — Supports local FLAC, ALAC, WAV, MP3, M4A, and DSD with parametric EQ and bit-perfect USB DAC output.
