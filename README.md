# Zen

A Liquid-Glass Android music player with high-resolution audio streaming, offline playback, time-synced lyrics, and native Discord Rich Presence.

## Features
- **Liquid Glass UI** — Real-time backdrop blur, dynamic album-art mesh gradients, and 120Hz high-refresh-rate rendering.
- **Native Discord Rich Presence** — OAuth2 PKCE handshake + Discord Social SDK broadcasting live track status, cover art, and timestamps.
- **Lossless & Offline Playback** — Supports local FLAC, ALAC, WAV, MP3, M4A, and DSD with parametric EQ and bit-perfect USB DAC output.
- **Smart Library & Playlists** — Fast artist-and-album playlist sorting, local folder browsing, and Google Drive backup sync.
